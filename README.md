# Brunch Santo Tomé · web de demostración

Maqueta de web para **Brunch Confitería Santo Tomé** (Av. de Irlanda, 3 · 45005 Toledo),
obrador y cafetería 100% sin gluten.

Web estática (HTML + CSS + JS, sin dependencias). Para verla, abre `index.html` en el navegador
o publícala gratis en GitHub Pages / Netlify.
